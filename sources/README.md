# Source register

Use `source-register.yml` to record authoritative sources used by EKOS documents.

For each source record:
- stable source ID;
- title and URL;
- publisher/owner;
- source type;
- scope or product version;
- date accessed;
- notes on which topics it supports.

Prefer linking to official documentation rather than copying it. Record community sources separately and do not treat them as proof without corroboration.
