Provide a source-backed, practical engineering reference for GitHub Actions, from fundamentals through advanced workflow design, security, enterprise operation and troubleshooting.

This encyclopedia covers:
- conceptual and architectural understanding;
- workflow syntax and event semantics;
- jobs, steps, expressions and contexts;
- runners and reusable components;
- artifacts, caching and environments;
- security, permissions and OIDC;
- integrations and deployment patterns;
- debugging, troubleshooting and edge cases;
- tested examples and production-oriented case studies.
