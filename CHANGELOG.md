# Changelog

## 0.1.0 — 2026-11-11

- Initialized EKOS architecture and local-first principles.
- Defined EKDS documentation standard.
- Added GitHub Actions encyclopedia master index.
- Added reusable knowledge templates and metadata schema.
- Added initial metadata validation utility.

## 0.2.0 — 2026-11-11

- Started Milestone 2: GitHub Actions encyclopedia.
- Added five source-reviewed documents covering fundamentals, architecture, workflow lifecycle, runner routing and basic syntax.
- Added a manual-dispatch experiment guide and starter workflow YAML.
- Expanded the official GitHub source register.
- Updated the GitHub Actions master index, project README, architecture and roadmap.
- Kept all knowledge as portable Markdown/YAML; no runtime dependencies added.

## Milestone 3 — Knowledge Quality Gate
- Added dependency-free validator with text/JSON output and strict mode.
- Added checks for required metadata, ID format/uniqueness, statuses, review dates, source IDs, required sections and relative links.
- Updated README, architecture and roadmap with setup and usage instructions.

## Milestone 4 — Local Knowledge Indexing Engine
- Added SQLite/FTS5 local index builder.
- Added full-text search and metadata filters.
- Added document relationship and source navigation commands.
- Added automated unit tests and Windows usage guide.
- Updated README, architecture and roadmap.

## Milestone 5 — Local Knowledge Explorer
- Added localhost-only Python HTTP server and JSON endpoints.
- Added browser UI for search, metadata filters, document reading, relationships and source navigation.
- Added retrieval-ready Ask EKOS panel without AI-generated answers.
- Added API integration tests and Windows startup scripts.
- Updated README, architecture and roadmap.
